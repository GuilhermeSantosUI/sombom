# SomBom

Aplicativo mobile para mapeamento colaborativo de ruído urbano e proteção da saúde auditiva. O SomBom permite medir o nível de ruído em tempo real (offline-first), registrar incômodos sonoros de forma anônima e visualizar um mapa coletivo de ruído por região, servindo tanto ao morador que quer entender e comprovar o barulho que o incomoda quanto a urbanistas e órgãos de fiscalização que precisam de dados agregados para embasar decisões.
